# 潜流 · Undercurrent —— 设计文档

> 一款**低频干预**、**AI 原生**、以**潜空间世界模型**为引擎的模拟游戏。
> 你不是统治者，也不是建造者。你是一个只能偶尔"扰动梦境"的存在，
> 世界在一个学习得到的潜空间中自行演化，而世界里的人会试图理解你。

---

## 1. 一句话与核心体验

**一句话**：你守望一个由世界模型"梦"出来的文明。每一百年你只能降下两三次"征兆"——
在潜空间中沿某个方向轻推一下——然后看着几百条可能的未来坍缩成一条历史。

**三个情绪支点**

| 支点 | 玩家感受到的 | 由什么机制产生 |
|---|---|---|
| 敬畏 | "这个世界不是我写的，它有自己的意志。" | 潜空间动力学有吸引子、相变、自发叙事 |
| 求知 | "我开始懂它的规律了。" | 征兆语义未知、纠缠、依赖状态，需要像科学家一样实验 |
| 被凝视 | "他们在议论我。" | 居民（LLM 代理）把你的干预编进神话、宗教、科学，并反过来改变世界 |

**为什么低频**：低频干预让每次决定都有分量；"大部分时间你只是看着"本身就是玩法——
它把注意力从操作转移到**观察、推理和讲故事**上，也天然适合异步/放置节奏
（一次会话 10 分钟，或者每天看一眼）。

---

## 2. 为什么"潜空间世界模型"不是噱头

传统模拟游戏的状态是显式的（人口=1234、粮食=56），规则由设计师逐条手写。
潜空间世界模型（Dreamer/RSSM、Genie 类可交互视频模型、JEPA 类预测模型）的状态是一个
**没有直接语义的向量 z**，转移规则 `z' = f(z, a) + ε` 是从数据里学来的。

这带来三个**传统引擎做不到、恰好能变成玩法**的性质：

1. **语义是不透明的** → 理解世界本身成为核心循环（"潜空间考古学"）。
2. **动力学是随机的** → 未来天然是一个分布；"预言"就是对模型采样，成本真实可控。
3. **一切维度纠缠** → 没有"只加雨水"的按钮；每个干预都有副作用，深度从这里来。

再加上"模型会做梦"（分布外漂移/幻觉），我们不压制它，而把它包装成**梦蚀**机制（见 §4.5）。

## 3. 核心循环

```
          ┌────────────── 一个纪元（≈25 年，几十秒到几分钟实时） ──────────────┐
观察 ──▶ 假设 ──▶ 预言（采样未来之雾） ──▶ 干预（0–2 次征兆） ──▶ 时间流淌 ──▶ 解读编年史
  ▲                                                                              │
  └──────────────── 更新"征兆图鉴"、居民对你的信仰/理论改变世界 ◀──────────────┘
```

- **观察**：你看到的只是解码器 `decode(z)` 渲染出的世界——地图画面、少数几个可读指标、编年史。
- **假设**："灰雾好像总伴随信仰上升？是不是只在干旱时这样？"
- **预言**：花费稀缺的"灵视"，从当前状态（可附带一个假设干预）采样 N 条未来，
  看繁荣度/任一指标的分位数扇形图——**你在操纵的是概率质量，不是结果**。
- **干预**：每纪元 2 次"注意力"。选择征兆和强度。
- **时间流淌**：快进，不可打断（或只能以高昂代价打断）。
- **解读**：编年史由居民视角写成，他们会误读、神化或研究你的征兆。

## 4. 系统设计

### 4.1 世界状态与解码

- 真状态：`z ∈ R^d`（原型 d=6；完整版可为数百维的 RSSM 隐状态 + 每个区域/派系的局部潜变量）。
- 解码器分三层，让同一个 z 被不同"感官"读出：
  1. **画面解码**：地图/视频帧（扩散解码器或可交互视频模型）。
  2. **指标探针**：在 z 上训练的线性探针给出 6–12 个可读指标（雨水、人口、信仰……）。
     **刻意不给全**——有些重要维度没有探针，玩家只能从画面和叙事里间接感知。
  3. **叙事解码**：把 z 的变化（及其 SAE 特征激活）交给 LLM，生成居民视角的编年史。

### 4.2 征兆：潜空间中的方向

- 征兆 = 潜空间中的一个方向向量 `v`，可由**稀疏自编码器（SAE）特征**或对比样本的差向量得到，
  所以它们"有某种意义"，但不是设计师逐条写死的。
- 玩家只拿到名字和一句谶语（"大地深处传来金属的回响"）。
- 真实效果 = `decode(z + αv) - decode(z)`，**依赖当前状态**（sigmoid/非线性导致饱和、
  吸引子边界附近被放大）——同一个征兆在丰年和荒年意义不同。
- **征兆图鉴**自动记录每次观测到的即时效果，但只是平均值；玩家必须自己发现条件性。
- 后期解锁：**征兆合成**（向量相加）、**反向征兆**（−v）、**锚定**（固定某维度一段时间，代价高）。
- **反向征兆（原型已实现）**：观测过 2 次的征兆可以逆转（`−v`），各有名字（甘霖→旱风、彗星→星隐、共梦→无梦之夜、
  灰雾→春潮、地鸣→地息、静默→喧嚣）。逆转从未在世界中自然出现，居民毫无预期（易引发恐慌），梦蚀 ×1.3。
  规划器测试显示它短期诱人、长期常亏——是只在特定时机使用的工具。
- **锚定（原型已实现）**：花掉一个纪元的全部注意力（2 点），把一个指标钉在当前值上 25 年。
  实现上每年沿该维度把 z 拉回（`z += Winv[:,k]·(logit(目标) − l_k)`），每年梦蚀 +0.9%（一个纪元约 +20%）。
  梦蚀中解码器漂移而锚定仍用原逆映射，所以锚会"打滑"并把扰动泄漏到其他维度。
  规划器测试：可选锚定时平均每局使用约 5 次，繁荣 0.33 → 0.36——强力但昂贵的防守手段。
- **征兆合成（原型已实现）**：
  - 只有**观测过**的征兆才能参与合成——你无法组合你不理解的东西。
  - 一次合成只花 1 点注意力，两个方向各以 0.6 倍同时推动（`v = 0.6·(v₁+v₂)`）。
  - 15 种组合各有名字（甘霖+彗星=星雨、灰雾+地鸣=毒烟、共梦+静默=长眠……）和独立的合成图鉴条目。
  - 居民对组合的预期 = `max(E₁·E₂, E_组合)`：新组合几乎无法被对冲，但更容易引发恐慌；
    反复使用同一组合，居民也会学会它本身（重复同一组合平均被对冲约 41%）。
  - "不自然的组合"更快地离开流形：梦蚀增量 ×2。
  - 平衡：预见 25 年的贪心规划在允许合成时繁荣度 0.27 → 0.33。合成是"理解"换来的力量，代价是梦蚀。

### 4.3 预言与未来之雾

- 预言 = 从当前 z 并行采样 N 条 rollout，显示分位数扇形（原型已实现：灰=不干预，金=干预）。
- 资源"灵视"稀缺：要么看得多、要么干预得准，二者权衡。
- 深度来源：玩家逐渐学会读**雾的形状**——双峰分布意味着临近分岔点（此时小干预影响巨大），
  雾很窄说明处于深吸引子里（此时干预几乎无效，不如省下来）。
  这就是"**在混沌边缘出手**"的技巧，也是高手与新手的分水岭。

### 4.4 居民：被凝视的反身性

- 居民不是 NPC 小兵，而是若干 **LLM 代理代表的派系/思想流派**（祭司、学者、商团、异端……）。
- 每次征兆后，各派系根据自身状态给出**解释**，解释写回世界：
  - 祭司把"彗星"解释为神罚 → 信仰↑ 纷争↑（解释本身就是潜空间里的一个推动）
  - 学者开始记录规律 → 若你反复使用同一征兆，他们会**预测你**，提前囤粮/迁徙，
    你的干预效果因此**被对冲**。
- 结果：玩家的行为模式成为世界的一部分。太规律，世界会"适应你"；太随机，居民陷入恐慌。
  这形成一个**关于"如何当神"的元博弈**。
- **原型实现（`sim.js` 中的 `intervene` / `anticipate`）**：
  - 学者预测力 = `clamp(0.15 + 0.85·技艺 − 0.35·信仰)`：文明越重视记录与观测，越能预测你；被教义主导时则不能。
  - 每个征兆有一个"被预期度" `E ∈ [0,1]`。纪元结束时 `E ← 0.55·E + 0.5·(本纪元使用次数/2)·(0.4+0.6·预测力)`，
    崇拜该征兆的教派（累计使用 ≥5 次）额外提高预测。
  - **对冲**：降下被预期的征兆时，效果被削弱 `min(0.85, E·(0.35+0.65·预测力))`。
  - **提前准备**：纪元结束时，对 `E·预测力 > 0.25` 的征兆，居民会沿反方向小幅推动世界——即使你这次没有降下它，
    准备也已发生（例如为"灰雾"迁离河谷，若灰雾不来就是白白付出的代价）。
  - **震惊**：完全意料之外的征兆会沿"恐慌方向"（纷争↑ 信仰↑ 人口↓）额外推动，强度 ∝ (1−E)²·(0.3+信仰)。
  - 所以既不能太有规律（被对冲），也不能太随机（引发恐慌），而且居民的预测力本身取决于你把文明推向何方。
- **LLM 居民（原型已实现，可选，`prototype/residents.js`）**：
  - 玩家在页面上填写自己的 Anthropic API 密钥并启用。浏览器用官方 TypeScript SDK（`@anthropic-ai/sdk@1.1.0`，
    启用时才从 CDN 动态加载）直连 `api.anthropic.com`，模型 `claude-opus-5-5`，`effort: low`。
    密钥只存在本机（勾选"记住"才写入 localStorage）。
  - 每个纪元结束时发送**居民可感知的摘要**：纪元起止指标、梦蚀、学者预测力、本纪元征兆（名称/类型/是否被预料/是否恐慌/累计次数）、
    噩梦、学者的准备、锚定、教派、之前 3 个纪元的理论。**不发送世界愿望**，也不发送潜状态。
  - 用 JSON schema 结构化输出：`chronicle`（2–4 条）、`factions`（祭司/学者/商团/异端 × 崇拜/研究/利用/反抗/漠视）、
    `theory`（居民对守望者的集体理论，跨纪元延续）、`nudges`（至多 2 条，只能是"指标 + 方向"）。
  - 写回世界：`Sim.residentNudge` 把每条行动固定为 ±0.25 logit，客户端再次校验枚举、条数与长度；所有文本转义后才显示。
  - 失败兜底：没有密钥、网络错误、`stop_reason: refusal`/`max_tokens` 时，本纪元回退到模板编年史；
    请求带 `fallbacks: "default"`（beta `server-side-fallback-2026-07-01`），安全分类器误拒时由服务端换模型重试。
- 工程上：LLM 只在纪元边界低频调用（一次纪元 1–3 次），输出结构化 JSON
  （解释文本 + 对少数 SAE 特征的小幅推动），成本与延迟可控，且完全符合低频节奏。

### 4.5 梦蚀：把幻觉变成机制

- 学习型世界模型在分布外会漂移（物体变形、规则失效）。设计上：
  - 维持一个**一致性度量**（如重建误差/模型集成分歧）。
  - 过度干预（强度大、频率高）会把 z 推离训练流形 → 世界开始"做噩梦"：画面扭曲、
    编年史出现不可能的事件、指标失去意义。
  - 梦蚀既是**惩罚**（世界变得不可预测，预言失效），也是**诱惑**（流形之外有稀有结局和奇异文明）。
- 这给了"低频干预"一个内生的理由，而不是硬性的冷却时间。
- **原型实现**：
  - 梦蚀 `e ∈ [0,1]`：每次干预 `+0.05·强度²·放大`，每年 ×0.985（半衰期约 2 个纪元）。强度的平方意味着"一次猛推"远比"两次轻推"危险。
  - 解码器漂移：`Wd(t) = Wd + 0.55·e·(cos(t/30)·A + sin(t/30)·B)`。动力学仍用原逆映射推进，
    所以指标的含义悄悄改变、因果规则开始失灵，征兆图鉴变得不可靠（指标名后出现"?"）。
  - 潜空间噪声 ×(1+2.5e)：未来之雾变宽，预言失去价值。
  - 噩梦：`e > 0.35` 后每年以 `0.8·(e−0.35)` 的概率，世界自发"梦到"一个随机征兆（随机正反方向）并伴随恐慌。
  - 诱惑：梦蚀中干预被放大 ×(1+0.8e)；有 ≥3 个纪元结束于深度梦蚀并存活，可得结局"梦外之主"。
  - 表现：地图出现青/品红噪点、整行错位、色相漂移；编年史出现不可能事件。

### 4.6 目标与结局

- 默认目标不是"最大化人口"，而是**繁荣度的时间积分**（原型：人口 × 和平 × 沃土 × 多样性惩罚）。
  它惩罚把一切押在单一维度上——例如原型中"地鸣"带来技艺爆发，
  但若不加以平衡，会导致工业干旱崩溃（无干预时也常见的一种吸引子）。
- 隐藏的**世界愿望**：每个种子世界有 1–2 个隐藏的长期倾向（"这片土地想要海"），
  顺应它会解锁特殊结局。
- **世界愿望（原型已实现，每个世界 1 个）**：

  | 愿望 | 条件（连续满足 30 年） | 拉力 |
  |---|---|---|
  | 海 | 雨水 > 0.75 且人口 > 0.2 | 雨水 |
  | 火 | 技艺 > 0.75、纷争 < 0.35、沃土 > 0.25 | 技艺 |
  | 神 | 信仰 > 0.72、纷争 < 0.35、人口 > 0.25 | 信仰 |
  | 繁衍 | 人口 > 0.68、沃土 > 0.3 | 人口、沃土 |
  | 荒野 | 人口 < 0.35、沃土 > 0.5 | 沃土↑ 人口↓ |
  | 寂静 | 纷争 < 0.06、信仰 < 0.2、人口 > 0.45 | 纷争↓ 信仰↓ |

  - 世界会以很小的力（0.2×拉力，logit/年）持续漂向愿望——**这种倾向本身就是可以从数据里读出的线索**。
  - 编年史在纪元开始时给出暗示，越往后越明确（"孩子们在干涸的河床上画波浪"→"人们梦见无边的水"）。
  - 处于愿望状态时，地图边框发出橙光，"大地"一栏显示"满足 n/30 年"，编年史写"大地似乎很满足"。
  - 实现后：梦蚀清零，愿望拉力减为 30%，结局标题追加"·X 之愿"；结局总会揭示愿望是什么。
  - 愿望不一定与繁荣一致："火"可能把文明推向工业干旱；"荒野"要求人口稀少——顺应大地，还是守护人类，是玩家的选择。
  - 测量（每种愿望 6 个种子）：不干预时实现率 0–33%；知道愿望的规划器 67–100%，唯"荒野"约 33%（与繁荣直接冲突，最难）。
- 结局由居民写成史书：你在他们的经书里是谁？园丁、暴君、沉默的神，还是从未被察觉的存在。

## 5. 深度从哪里来（设计自检）

| 深度来源 | 玩家需要掌握的 |
|---|---|
| 纠缠 | 用两个征兆的组合抵消副作用 |
| 状态依赖 | 在对的时机用对的征兆（饱和区无效，分岔点放大） |
| 随机与不确定性 | 读雾的形状，决定"花灵视看"还是"省下来干预" |
| 延迟效果 | 很多征兆的主要后果在 30–80 年后才显现 |
| 反身性 | 居民会学习你；你的模式本身是变量 |
| 梦蚀 | 力度与世界稳定性之间的权衡 |
| 种子多样性 | 每个世界的解码器旋转不同，图鉴不能完全跨局复用，但"方法论"可以 |

最后一条很关键：**跨局保留的是玩家的理解能力，而不是数值**——这是推理类游戏
（Outer Wilds、Return of the Obra Dinn）式的成长，嫁接到模拟游戏上。

## 6. 技术路线

### 阶段 0：可玩原型（本仓库 `prototype/`，已完成）
- 手写 6 维潜空间动力系统代替学习模型：因果规则写在可观测量上，经随机混合解码器拉回潜空间推进；
  噪声注入潜空间，因此天然纠缠。
- 实现：征兆、强度、预言扇形图、征兆图鉴、模板编年史、神话/教派涌现、12 纪元结局、
  **梦蚀**（§4.5）、**居民预测/对冲/震惊**（§4.4）、**征兆合成**（§4.2）与**世界愿望**（§4.6）。
- 测量（8–16 个种子，300 年平均繁荣度）：

  | 策略 | 繁荣 | 平均梦蚀 | 平均被对冲 |
  |---|---|---|---|
  | 不干预 | 0.17 | 0 | — |
  | 每纪元 2 次，强度 1，预见 25 年的贪心规划 | 0.30（σ 0.07） | 0.22 | 24% |
  | 同上但强度 1.6 | 0.33（σ 0.11，最差局更低） | 0.56 | 13% |
  | 每纪元重复同一征兆 ×2 | 0.28 | 0.25 | 62% |
  | 每纪元强度 1.6 无脑干预 | 0.12（低于不干预） | 0.71 | 31% |

  → 加入两个机制前，全知贪心可达 0.37；现在规律性被惩罚，猛推是高方差的赌博，乱推比不推更糟。
  （以上为加入世界愿望前的测量；愿望的轻微拉力使不干预基线升至约 0.19，贪心约 0.27–0.29，允许合成约 0.33。）

### 阶段 1：学习型潜空间
- 用阶段 0 的规则引擎 + 一个更丰富的基于代理的模拟器（多区域、多派系）**生成大量轨迹**，
  训练 RSSM/Transformer 世界模型；在潜空间上训练 SAE，从中挑选可解释特征作为征兆候选。
- 好处：模型**会泛化出设计师没写过的行为**，同时有显式模拟器作为真值来调平衡。
- 端侧可行：数百维潜状态 + 小 MLP/Transformer 转移，CPU/WebGPU 每秒可跑上千步，
  预言的 N×25 步 rollout 毫秒级。

### 阶段 2：画面解码
- 小型扩散/VAE 解码器把 z（+ 区域潜变量）渲染为地图帧；或对接可交互视频世界模型。
- 渲染只是"感官"，游戏逻辑始终在 z 上，保证一致性与可存档。

### 阶段 3：LLM 居民与叙事（原型已有可选实现，见 §4.4）
- 纪元边界调用 LLM：输入 = 近期指标轨迹 + 激活最强的 SAE 特征标签 + 征兆记录 + 派系记忆；
  输出 = 结构化 JSON（编年史条目、各派系解释、对少量特征的推动建议，限幅）。
- 推动需经过"限幅 + 一致性检查"再写回 z，防止 LLM 直接接管世界。

### 风险与对策
| 风险 | 对策 |
|---|---|
| 学习模型不可控、平衡难调 | 保留显式模拟器为真值；SAE 特征筛选；奖励函数在显式状态上计算 |
| 玩家觉得"什么都不做"无聊 | 编年史与画面持续有涌现事件；预言是低成本的"思考型操作"；可快进 |
| 黑箱感太强、挫败 | 图鉴自动记录；首个纪元给出教学性的强信号征兆；雾图可视化不确定性 |
| LLM 成本/延迟 | 只在纪元边界低频调用；可本地小模型；模板兜底（原型即模板版） |

## 7. 可以继续探索的变体

- **多人守望**：多个玩家各控制不同征兆子空间，在同一个世界里博弈或协作，居民会分辨出"不同的神"。
- **观测即干预**：预言本身会轻微扰动世界（量子味的规则），让"看"也有代价。
- **继承**：一局结束的潜状态作为下一局的初始神话层，跨局叙事延续。
- **反向模式**：你扮演居民中的学者，试图推断"神"（AI 控制的征兆策略）的意图。

## 附录：原型数值设定

见 `prototype/sim.js`。关键参数：
- 6 个可观测量：雨水、沃土、人口、信仰、纷争、技艺。
- 解码器 `Wd = I + 0.35·N(0,1)`（每个种子不同），征兆在可观测 logit 空间的效果经 `Wd⁻¹` 映射为潜向量。
- 每年 `dt = 0.22`，潜空间噪声 σ = 0.09。
- 繁荣度 = `人口 × (1−纷争) × (0.6+0.4·沃土) × (1−0.6·指标离散度)`。
- 梦蚀与居民预测的参数见 §4.4、§4.5 的"原型实现"。
