# 潜流 · Undercurrent

一款**低频干预 · AI 原生 · 潜空间世界模型驱动**的模拟游戏概念与可玩原型。

你守望一个由世界模型"梦"出来的文明。每个纪元你只能降下两次"征兆"——在潜空间中沿某个方向轻推一下——
然后看着无数可能的未来坍缩成一条历史。世界里的人会试图理解你。

- 设计文档：[`docs/DESIGN.md`](docs/DESIGN.md)
- 可玩原型：[`prototype/index.html`](prototype/index.html)（纯静态，无依赖，直接用浏览器打开）
- 学习型世界模型：[`model/`](model/README.md)（从规则世界的轨迹训练，游戏中可切换为"学习到的世界模型"引擎）

## 运行原型

```bash
cd prototype && python3 -m http.server 8000
# 打开 http://localhost:8000/?seed=42
```

或直接双击 `prototype/index.html`。URL 参数 `?seed=N` 可复现同一个世界，`?engine=learned` 使用学习到的世界模型（也可在顶栏切换）。

## 玩法速览

1. 观察地图与六个解码指标（你看不到真实的潜状态）。
2. 选择一个征兆，用「预言」花费灵视，比较"不干预"与"干预"两团未来之雾。
3. 「降下征兆」：每纪元 2 次。效果会记录进征兆图鉴——但它依赖时机。
4. 「让时间流淌」25 年，阅读编年史：居民如何解读你。
5. **梦蚀**：用力过猛（强度的平方计）会让世界"做梦"——指标失去含义、未来之雾变宽、噩梦自发降临。
6. **居民会预测你**：重复使用的征兆会被学者预料并对冲；完全意外的征兆则引发恐慌。看征兆卡上的"被预期"条。
7. **征兆合成**：观测过两个征兆后，开启「合成模式」把它们合成一次干预（如 甘霖+彗星=星雨）。新组合难以被预料，但梦蚀 ×2。
8. **逆转与锚定**：观测过 2 次的征兆可以「逆转」（甘霖→旱风）。「锚定」花掉整个纪元的注意力，把一个指标钉住 25 年，代价是持续的梦蚀。
9. **世界愿望**：每个世界都有一个隐藏的愿望。留意编年史里的橙色暗示和"大地"一栏；连续满足 30 年即可实现。
10. **居民之声（可选）**：在页面底部填入你的 Anthropic API 密钥并启用，每个纪元结束时由 Claude 扮演居民写编年史、解读征兆、形成关于你的理论，并采取至多 2 次有限的集体行动。密钥只保存在你的浏览器里，只发送给 api.anthropic.com；不启用时使用模板编年史。
11. 12 个纪元后结算。参考：不干预 ≈ 0.19，能预见未来的贪心规划 ≈ 0.27，加上合成 ≈ 0.33。
