# 潜流 · Undercurrent

一款**低频干预 · AI 原生 · 潜空间世界模型驱动**的模拟游戏概念与可玩原型。

你守望一个由世界模型"梦"出来的文明。每个纪元你只能降下两次"征兆"——在潜空间中沿某个方向轻推一下——
然后看着无数可能的未来坍缩成一条历史。世界里的人会试图理解你。

- 设计文档：[`docs/DESIGN.md`](docs/DESIGN.md)
- 可玩原型：[`prototype/index.html`](prototype/index.html)（纯静态，无依赖，直接用浏览器打开）

## 运行原型

```bash
cd prototype && python3 -m http.server 8000
# 打开 http://localhost:8000/?seed=42
```

或直接双击 `prototype/index.html`。URL 参数 `?seed=N` 可复现同一个世界。

## 玩法速览

1. 观察地图与六个解码指标（你看不到真实的潜状态）。
2. 选择一个征兆，用「预言」花费灵视，比较"不干预"与"干预"两团未来之雾。
3. 「降下征兆」：每纪元 2 次。效果会记录进征兆图鉴——但它依赖时机。
4. 「让时间流淌」25 年，阅读编年史：居民如何解读你。
5. **梦蚀**：用力过猛（强度的平方计）会让世界"做梦"——指标失去含义、未来之雾变宽、噩梦自发降临。
6. **居民会预测你**：重复使用的征兆会被学者预料并对冲；完全意外的征兆则引发恐慌。看征兆卡上的"被预期"条。
7. 12 个纪元后结算。参考：不干预 ≈ 0.17，能预见未来的贪心规划 ≈ 0.30。
